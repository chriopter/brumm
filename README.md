# ʕ•ᴥ•ʔ brumm

Apple Music for [Omarchy](https://omarchy.org): a background player with media keys, a bar widget and a terminal UI.

Inspired by [vibez](https://github.com/simonepelosi/vibez).

## Development

```sh
bin/setup   # Build and install into Omarchy, then `brumm login` once
bin/dev     # Run the daemon in the foreground (`bin/dev ui` for the TUI)
bin/update  # Pull and reinstall
```
