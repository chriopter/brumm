# ʕ•ᴥ•ʔ brumm 1.0.0: Explore, Replay and videos

![Explore with album covers and the glass player](https://github.com/chriopter/brumm/raw/v1.0.0/docs/release-1.0.0.webp)

## New
- 🧭 Explore has charts, genres and music videos.
- ❤️ Favorites and Replay are on Home.
- 📁 Browse playlist folders and create playlists.
- 🎬 Watch music video previews in the GUI.
- 🔎 More search results. Press <kbd>Ctrl+i</kbd> for details.

## Changed
- 🪟 New navigation. Click Now Playing for the cover.

## Fixed
- 🖱️ Right-click opens actions for the selected item.

**Update:** press <kbd>U</kbd> when brumm offers it, or run `brumm update`. Video previews need `qt6-multimedia` on Arch and Omarchy. The installer includes it; existing installs can run `sudo pacman -S --needed qt6-multimedia`.
